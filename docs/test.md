
| Action | Drift |
|---|---|
| Focus column/window left | Meta+Left |
| Focus column/window right | Meta+Right |
| Focus window above (in-column) | Meta+Up |
| Focus window below (in-column) | Meta+Down |
| Focus first/last column | Meta+Home / Meta+End |
| Move column left | Meta+Ctrl+Left |
| Move column right | Meta+Ctrl+Right |
| Move window up/down (in-column) | Meta+Ctrl+Up / Meta+Ctrl+Down |
| Move column/window to start/end | Meta+Ctrl+Home / Meta+Ctrl+End |
| Cycle column width presets | `Meta+R` (+`Shift` reverse) |
| Increase/decrease column width | `Meta+Plus` / `Meta+Minus` |
| Increase/decrease window height | `Meta+Shift+Plus` / `Meta+Shift+Minus` |
| Center focused column | Meta+C |
| Cycle column align (left/center/right) | Meta+Shift+Left / Meta+Shift+Right |
| Scroll viewport without changing focus | `Meta+Alt+Left` / `Meta+Alt+Right` |
| Scroll viewport to start/end | `Meta+Alt+Home` / `Meta+Alt+End` |
| Absorb/expel window (vertical stacking) | `Meta+I (absorb) / Meta+O (expel)` |
| Toggle floating | Meta+Space |
| Switch workspace/strip up | `Meta+Page_Up` |
| Switch workspace/strip down | `Meta+Page_Down` |
| Move column to workspace/strip above | `Meta+Ctrl+Page_Up` |
| Move column to workspace/strip below | `Meta+Ctrl+Page_Down` |
