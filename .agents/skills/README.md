Most skills are adaptations of the skills available in the ["superpowers"](https://github.com/obra/superpowers) repository.
They were stripped down and adapted to fit the needs of this project, and to be more easily used by a variety of agents.

The license for the original superpowers repository is MIT and applies to the skills in this directory that were adapted from that repository.
